## 탐구 구조

출처: AI 기반 물리 시뮬레이션 교육 · 전남대학교 물리교육과.

최상위 메뉴는 **무한 퍼텐셜 우물 / 조화진동자 / 자유입자**입니다. 자유입자 하위 메뉴는 평면파 → 중첩 → 푸리에 변환 → 파동묶음의 운동 → 무한 벽 반사 순서입니다. 푸리에 변환 1~3단계는 무한우물의 사인 기저, 4단계는 자유입자의 연속 평면파 기저를 사용합니다.

무한 퍼텐셜 우물에서는 n, m=1~8의 두 에너지 고유상태, 둘째 상태의 확률 가중치와 상대 위상을 조절합니다. q=0, 1은 에너지 고유상태 하나이고 n=m이면 해당 상태 하나를 표시합니다. 길이 L, 에너지 E₁=π²ℏ²/(2mL²), 시간 ℏ/E₁ 단위입니다. 양쪽 벽에서 Ψ=0을 만족하며 에너지 측정 확률과 평균 에너지는 보존됩니다. `well_ui.py`도 실행·배포에 필요합니다.

## 용어 기준

수업 표기를 따라 일반 파동함수는 Ψ(x,t), 에너지 고유함수는 ψₙ(x)로 씁니다. 기존 uₙ을 ψₙ으로 바꿨으며, 시간 진화는 Ψ=Σcₙψₙexp(−iEₙt/ℏ)입니다. 그래프의 초기 진폭 기준은 A₀로 표시하여 바닥상태 ψ₀와 구분합니다. 우물의 q는 둘째 상태의 확률 가중치로 그대로 유지합니다.

앱은 **에너지 고유상태**를 기본 용어로 사용합니다. Ĥψₙ=Eₙψₙ이고 시간에 무관한 퍼텐셜에서 Ψₙ(x,t)=ψₙ(x)exp(−iEₙt/ℏ)로 진화합니다. 이 상태는 확률밀도가 일정하므로 **정상상태(stationary state)**라고 합니다. 서로 다른 에너지 고유상태의 중첩은 일반적으로 정상상태가 아닙니다. ‘간섭’은 합성 파동함수의 확률밀도에 생기는 교차항을 뜻합니다. 직교성이 교차항을 각 위치에서 없애는 것은 아닙니다. 일반적인 ‘고유상태’는 어떤 관측량의 고유상태인지 명시해야 합니다.

근거: [MIT Quantum Physics II · Stationary Solutions](https://live.ocw.mit.edu/courses/8-05-quantum-physics-ii-fall-2013/61bc31b8d8bf0680c322733910a71aa0_MIT8_05F13_Chap_01.pdf).

## 기존 탐구 주제

1. **평면파:** Re[Ψ], Im[Ψ], 일정한 상대 |Ψ|², 단일 파수. 운동량이 정해져도 위치는 국소화되지 않습니다. 이상적 평면파는 전체 공간에서 정규화할 수 없고 화면 폭을 위치 불확정성으로 계산하지 않습니다. 위상 색은 실수부 Re[Ψ]/A 높이에 표시합니다. A를 양의 실수로 잡아 모든 마루는 위상 0, 골은 ±π이며 각각 같은 색입니다. 우물·조화진동자에서 위상 색을 |Ψ| 높이에 표시하는 것과 세로축 의미가 다릅니다.
2. **중첩과 불확정성:** 연속 가우스 목표에서 중심 파수부터 양쪽으로 평면파를 추가합니다. 성분 간격은 Δk_step=8σₖ/100으로 고정하고 N에 따라 포함 범위를 넓힙니다. 중심 파수, 목표 파수 표준편차, 포함 성분의 표준편차를 구분합니다. 대표 성분을 최대 5개의 별도 그래프로 보여줍니다. 소수 성분, 국소화된 파군, 좁은 파군 프리셋을 제공합니다. 위치 표준편차는 연속 가우스 목표의 해석값입니다. 별도로 표시한 포함 성분의 파수 표준편차는 현재 N개 성분의 진폭 제곱을 가중치로 계산합니다. N이 작은 유한합을 전체 실수축의 정규화 가능한 한 입자 상태로 오해하지 않도록 별도 설명과 가우스 목표선을 표시합니다.
3. **자유입자:** 정확한 가우스 해석해로 중심 이동과 퍼짐을 계산합니다. 질량, 초기 파수 폭, 시간을 바꿀 수 있습니다. 평균 위치 따라가기를 끄면 선택한 조건의 전체 시간 범위를 담는 고정 좌표로 관찰합니다. 초기 분포와 비교할 수 있습니다.
4. **무한 퍼텐셜 벽에서의 반사:** 자유입자 파동묶음과 같은 폭·파수·질량을 사용하고 초기 중심을 x₀=−18로 옮깁니다. x=0의 무한 퍼텐셜 벽에서 Ψ=0을 만족하는 정확한 거울상 해 Ψ=C[g(x,t)−g(−x,t)]를 사용합니다. 입사·반사 중 간섭, 반사 후 퍼짐, +k에서 −k로 옮겨가는 Fourier 분포를 관찰합니다. 개별 부분을 켜서 상쇄를 볼 수 있습니다. 평균 위치·폭·평균 파수·확률 총합을 표시합니다. 재생 종료 시간은 정확한 거울상 해의 평균 위치가 반사 후 −40에 도달하는 시간으로 계산합니다. 실제 반사 중 평균 위치는 단순한 고전 궤적과 다릅니다.

5. **조화진동자:** ℏ=m=ω=1의 단위로 n=0~12의 정규화된 에너지 고유상태를 중첩합니다. 각 상태의 상대 확률 가중치 wₙ과 초기 위상 θₙ(도)을 입력하며 cₙ=√(wₙ/Σw)exp(iθₙ)로 계산합니다. ‘섞기’는 파동함수의 순수상태 중첩이며 통계적 혼합이 아닙니다. 시간 변화는 각 성분의 정확한 위상 exp[−i(n+1/2)t]로 계산하고, 평균·분산은 사다리 연산자로 구해 표시 구간과 독립적으로 유지합니다. 퍼텐셜과 평균 에너지 기준선을 같은 에너지 축에 표시하고, 정규화한 파형을 평균 에너지 높이 위에 겹쳐 그립니다. 에너지 성분은 이산 확률 막대로 표시합니다. 입력 변경은 일시정지와 시간 초기화를 함께 수행합니다. 가중치가 모두 0인 경우 상태를 임의 대체하지 않고 입력 안내를 표시합니다.

바닥상태, n=0+1, n=0+2, 코히런트 상태(α=1.5) 예시를 제공합니다. 코히런트 예시의 n>12 생략 확률은 약 7.62×10⁻⁷이며 절단 후 정규화합니다. t=0~4π를 재생합니다. 위치 확률분포는 2π 후 되돌아오지만 전체 파동함수는 −1배가 되므로 위상 색은 π 바뀝니다. 4π 후에는 파동함수도 되돌아옵니다. 각 탐구 문항에는 접이식 해설이 있습니다.

6. **푸리에 변환:** 1. 직교성 → 2. 계수 추출 → 3. 부분합 재구성 → 4. 연속 변환 순서로 탐구합니다. 1~3단계는 [0,L]의 정규직교 사인 기저를 사용합니다. 양·음 곱의 면적, 누적 적분, 부호를 가진 계수, 원래 함수와 부분합, 적분 오차를 표시합니다. N은 1~60, m과 n은 1~40을 조절합니다. 목표 함수는 가우스형 봉우리(양끝을 0으로 만드는 사인 인자 포함), 삼각형, 치우친 봉우리, 비대칭 두 봉우리, 직사각형입니다. 비대칭 두 봉우리는 x/L=0.28의 좁은 봉우리와 x/L=0.70의 넓고 낮은 봉우리를 합하고 사인 인자로 양끝을 0으로 맞춥니다. 목표 함수는 제곱 적분을 1로 맞추지만 부분합은 재정규화하지 않습니다. 직사각형에는 잔물결과 Gibbs 현상의 표준 파수순 부분합을 구분하는 안내를 표시합니다.

4단계는 전체 실수축의 최소 불확정도 가우스와 정확한 연속 푸리에 변환입니다. σₓ, x₀, k₀를 조절하고 위치·파수 확률밀도와 복소 계수의 실수부·허수부를 비교합니다. x₀ 변화는 파수 밀도가 아닌 계수 위상에 반영됩니다. 정적 함수 전개를 탐구하므로 재생 제어는 숨깁니다. 각 단계에 접이식 해설과 CSV 저장을 제공합니다. 이산 사인 전개와 전체 실수축의 평면파 변환의 경계조건 차이를 명시합니다.

위치 그래프는 초기 기준 유지가 기본이며, 시간이 지나면 실제로 봉우리가 낮아집니다. 필요하면 현재 파형에 맞춘 y축 자동 조정으로 전환할 수 있습니다. y축 확대는 0.5~4배로 조절합니다. 자동 조정은 계산값을 바꾸지 않지만 화면의 높이 비율이 시간에 따라 달라지므로, 봉우리의 감소를 비교할 때는 초기 기준 유지와 1배 확대를 사용하세요.

재생·일시정지, 시간 슬라이더, 시간 초기화, 재생 속도를 제공합니다. 끝 시간에서 자동 정지합니다. 중첩 모드는 t=0의 합성에 집중하므로 재생을 사용하지 않습니다. 그래프 카메라 아이콘으로 PNG를 저장하고, 현재 데이터 CSV로 계산 결과를 내보낼 수 있습니다.

## 물리적 정의

### 양자 모형

ℏ=1이며 질량 m은 조절 가능합니다. 파수 폭 σₖ는 진폭 A(k)가 아닌 **파수 확률밀도 |A(k)|²의 표준편차**입니다.

```text
Δx₀ = 1/(2σₖ)
⟨x⟩ = k₀t/m
Δx(t) = Δx₀ sqrt(1 + [t/(2mΔx₀²)]²)
Δp = σₖ   (ℏ=1)
v_group = k₀/m
v_phase(k₀) = k₀/(2m)
```

가우스 파동함수의 실수부·허수부와 확률밀도는 서로 다른 양입니다.
그래프의 A₀는 t=0 연속 가우스의 중심 진폭 크기 |Ψ(x₀,0)|입니다. 확률밀도는 초기 최대값 A₀²으로 나누고 |Ψ|²/A₀²로 표시합니다. 기준값은 시간을 진행해도 바뀌지 않으므로 봉우리의 감소를 볼 수 있습니다. 정확한 자유입자 가우스의 전체 확률은 해석적으로 1이며 표시 구간에 맞춰 다시 정규화하지 않습니다. 유한 평면파 합은 전체 실수축에서 정규화된 상태가 아니므로 이 확률 총합 설명을 적용하지 않습니다. 중첩 모드의 N=1은 가우스 분포의 중심 파수 성분 하나이며, N>1과 같은 가중치·초기 진폭 기준으로 비교합니다. 평면파 탭의 임의 진폭 A와 구분합니다. 중첩 모드의 포함 범위는 k₀±[(N−1)/2]Δk_step입니다. N=101에서는 중심 파수 양쪽으로 파수 폭의 4배까지, k₀−4σₖ부터 k₀+4σₖ까지 101개 성분을 더합니다. 바깥 성분은 가중치가 작아 생략하므로 모든 파수를 포함한 정확한 가우스 파동묶음과는 작은 차이가 있는 이산 근사입니다. N을 아주 크게 해도 추가 진폭이 작으면 눈에 띄는 변화가 적을 수 있습니다.

### 무한 퍼텐셜 벽 반사의 위상 색

자유입자의 「무한 벽에서의 반사」는 확률밀도와 위상 색을 기본으로 표시합니다. 색 점의 높이는 |Ψ|/A₀, 색은 arg Ψ(x,t)이며 −π와 π는 같은 색입니다. 벽과 진폭이 초기 기준의 1% 이하인 부분은 표시하지 않습니다. 이는 계산을 자르는 것이 아니라 위상 표시만 숨기는 기준입니다.

평면파 위상은 kx−ℏk²t/(2m)+φ₀입니다. 반사계수 −1은 π의 위상 변화를 뜻하며, 반사파의 진행 방향은 −k입니다. 겹침 구간에서는 전체 파동함수의 위상을 표시합니다. 벽 반사 화면에는 대표 파수 성분별 색 원을 표시하지 않습니다. 중심 파수·파수 폭·질량을 바꾸면 재생을 멈추고 t=0에서 새 초기 상태를 준비합니다.

## 무한 퍼텐셜 벽 반사의 계산

x≤0에서 자유 가우스 해와 그 거울상 해를 빼서 경계조건을 만족합니다. 정규화 상수는 C=[1−exp(−x₀²/(2σx₀²)−2σx₀²k₀²)]^(−1/2)입니다. 이 연속 해석해는 확률 총합을 1로 유지하며 벽 내부로 확률이 새지 않습니다. 그래프 범위에서 다시 정규화하지 않습니다. 반사 중 입사·반사 부분은 함께 존재하고, 단일 순간에 전체 상태가 뒤집히지 않습니다.

파수 분포는 반직선 파동함수를 벽 내부에서 0으로 연장해 Fourier 변환한 것입니다. 벽이 있는 반직선에서의 운동량 관측량에는 경계조건상의 주의가 있으므로, 벽을 제거한 순간 해당 상태의 운동량 분포로 해석할 수 있음을 화면에 명시합니다. 계산에 사용하는 넓은 위치 구간과 표시 구간을 구분합니다. 생략되는 높은 파수 꼬리를 재정규화하지 않습니다.

시간 갱신에서는 파형·Fourier 분포·수치만 부분 갱신하고 설명과 축을 재생성하지 않습니다.

### 4번의 고정 좌표와 입력 변경

4번 위치 그래프는 중심 파수·초기 폭·질량을 바꾸어도 x축을 −60~3으로 고정합니다. 파형이 화면 밖으로 퍼져도 계산 구간과 전체 확률은 독립적으로 유지됩니다. 대표 파수 곡선과 색 원은 제거했습니다.

입력 변경 시 기존 시간이 남아 새 파동묶음이 이미 퍼진 상태로 나타나지 않도록 t=0으로 초기화하고 일시정지합니다. Fourier 계산 격자도 초기 파동묶음 폭과 최종 퍼짐 범위에 맞춰 정합니다.

위상 색 자체의 절대값은 관측량이 아닙니다. 상대 위상은 간섭을, 공간적 위상 기울기는 확률 흐름을 설명합니다.

4번에 벽 근처 x=−8~0의 위상 확대 패널을 추가했습니다. 입사 부분·반사 부분·합성파를 동일한 진폭 및 위상 색 눈금으로 표시합니다. 벽에서 입사와 반사의 상대 위상은 π이며 합성파는 0입니다. 이 패널의 세 행은 독립적인 확률분포가 아닙니다.

벽 확대 패널의 입사·반사 행 옆에 순환 위상 색 범례와 위상 화살표를 표시합니다. 같은 시각 x=0에서 계산하며 두 화살표는 π 차이로 반대 방향입니다. 화살표 길이는 진폭과 무관하며 작은 진폭에서는 표시하지 않습니다. 합성파는 벽에서 0이라 위상을 정의할 수 없습니다.

### 설명 점검과 해설

각 탭의 ‘예측·관찰·설명’ 문항에 닫힌 상태의 ‘해설 보기’를 추가했습니다. 해설은 `teaching_content.py`에서 관리합니다.

거울상 해의 가우스 함수는 g, 위상은 φ로 구분합니다. 4번의 초기 폭·파수 폭은 자유 가우스 기준값이며 실제 벽 상태의 폭과는 구분합니다. A₀는 실제 초기 벽 상태의 고정 기준 진폭입니다. k₀/σₖ가 작은 경우 초기 음의 파수 성분도 중요함을 안내합니다. 2번의 겹쳐 표시한 개별 성분도 실제 유한합의 계수로 표시합니다. 유한합에는 전체 공간에서 정규화한 위치 불확정성을 부여하지 않습니다.

조화진동자의 UI와 예시는 `harmonic_ui.py`, 에너지 고유상태·시간 변화·정확한 모멘트는 `physics.py`에서 관리합니다. 이 모델은 [MIT Quantum Physics II 강의노트](https://ocw.mit.edu/courses/8-05-quantum-physics-ii-fall-2013/79a8091ef4f18d8e3ff76a097e8db33c_MIT8_05F13_Chap_06.pdf)에 대조했습니다.

조화진동자 초기 조건의 ± 버튼은 앱에서 계산합니다. 가중치는 0.1, 위상은 15°씩 바뀌며 가중치는 0 아래로 내려가지 않습니다. 직접 입력한 소수 값도 유지합니다.

조화진동자의 파형 기준선은 ⟨E⟩/(ℏω)=Σ|cₙ|²(n+1/2)입니다. 표시 좌표는 그 값에 정규화된 파형 높이를 더합니다. 이는 에너지 편차가 아닌 시각화 관례이며 물리 계산과 CSV의 Ψ 값은 바꾸지 않습니다. 확률밀도 면적은 에너지 0 대신 평균 에너지 기준선까지 채웁니다.

배포할 때 `fourier_ui.py`도 `app.py`, `physics.py`, `harmonic_ui.py`, `well_ui.py`, `teaching_content.py`, `assets/` 폴더 전체, `pyproject.toml`과 함께 포함합니다. `uv.lock`과 실행 안내인 `README.md`도 포함하는 것을 권장합니다.

푸리에 변환 3단계는 추출한 n=1~60의 계수를 먼저 표시하고 |cₙ| 크기순으로 성분을 추가합니다. N은 포함한 성분 수이며 최대 양자수가 아닙니다. 막대의 부호를 유지하고 실제 n·추가 순서를 툴팁으로 보여줍니다. 같은 후보와 같은 N에서 제곱 오차 적분을 최소화하는 선택이며 부분합을 다시 정규화하지 않습니다.

설명 점검: 직사각형의 표준 Gibbs 현상은 낮은 파수부터 더하는 부분합에 대한 것이므로, 현재의 |cₙ| 크기순 선택에서 같은 국소 수렴 양상을 단정하지 않습니다. 우물 고유함수 ψₙ의 내부 영점 n−1은 중첩 Ψ에 적용하지 않습니다. 초기 진폭 A₀와 확률밀도 기준 A₀²을 구분하며, 중첩 탭의 파수 막대는 |A(kⱼ)|² 표본이고 실제 합성 계수는 A(kⱼ)Δk_step/√(2π)입니다.
